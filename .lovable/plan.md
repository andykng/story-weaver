

# 🔍 GitExplorer - Votre plateforme de découverte GitHub avec IA

Une application moderne et minimaliste pour découvrir, analyser et organiser des repositories GitHub avec l'aide de l'intelligence artificielle.

---

## 🎨 Design & Expérience Utilisateur

**Style moderne et épuré :**
- Interface claire avec beaucoup d'espace blanc
- Palette de couleurs neutres (blanc, gris, touches de bleu/violet pour les accents)
- Typographie moderne et lisible
- Sidebar collapsible pour la navigation
- Mode sombre disponible

---

## 🏠 Page d'accueil

- **Barre de recherche centrale** : Entrer une URL GitHub ou des mots-clés
- **Filtres par tags populaires** : python, javascript, ai, typescript, rust, etc.
- **Grille de repos recommandés** : Cartes avec nom, description, langage, étoiles
- **Accès rapide** aux fonctionnalités principales

---

## 🔎 Recherche & Découverte

- **Recherche par URL GitHub** : Coller directement un lien de repo
- **Recherche par mots-clés** : Trouver des repos par thème
- **Filtres avancés** :
  - Par langage de programmation
  - Par nombre d'étoiles
  - Par date de mise à jour
- **Affichage en grille ou liste** des résultats

---

## 🤖 Analyse IA du Code

**Fonctionnalités d'intelligence artificielle :**
- **Résumé automatique** : Description claire de ce que fait le repo
- **Analyse de la structure** : Explication de l'architecture du projet
- **Points clés** : Technologies utilisées, dépendances principales
- **Chat Q&A** : Poser des questions sur le code du repository

*Utilisation de Lovable AI pour alimenter ces fonctionnalités*

---

## 📚 Bibliothèque Personnelle

- **Sauvegarder des repos** en favoris
- **Organiser par collections** personnalisées
- **Notes personnelles** sur chaque repo sauvegardé
- **Historique** des repos consultés
- **Synchronisation** avec votre compte

---

## 👤 Authentification & Profil

- **Inscription/Connexion** par email
- **Profil utilisateur** avec préférences
- **Langages favoris** pour personnaliser les recommandations
- **Gestion des collections** de la bibliothèque

---

## 📱 Pages & Navigation

1. **Accueil** - Recherche + repos découverte
2. **Détail Repo** - Informations complètes + analyse IA
3. **Bibliothèque** - Repos sauvegardés et collections
4. **Profil** - Paramètres et préférences
5. **Authentification** - Login/Signup

---

## 🔧 Backend & Base de Données

**Lovable Cloud pour :**
- Authentification des utilisateurs
- Stockage des favoris et collections
- Historique de consultation
- Edge functions pour l'analyse IA

**Intégration GitHub API** pour récupérer les données des repositories
